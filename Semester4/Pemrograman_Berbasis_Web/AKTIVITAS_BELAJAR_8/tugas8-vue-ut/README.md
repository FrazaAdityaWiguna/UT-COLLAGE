# Tugas Praktik 2 – STSI4209 Pemrograman Berbasis Web

Aplikasi pemesanan bahan ajar SITTA UT berbasis **Vue.js 2** (dimuat via CDN).

## Struktur
```
tugas2-vue-ut/
├─ index.html        ← navigasi ke stok.html dan tracking.html
├─ stok.html         ← Halaman 1: Stok Bahan Ajar
├─ tracking.html     ← Halaman 2: Tracking DO
├─ css/style.css
├─ data/dataBahanAjar.js
└─ js/
   ├─ stok-app.js
   └─ tracking-app.js
```

## How to run
1. Pasang ekstensi **Live Server** — VS Code akan menyarankannya otomatis.
2. Klik kanan `index.html` → **Open with Live Server**.

Atau cukup klik dua kali `index.html` untuk membukanya di browser.
Pastikan internet aktif karena Vue.js dimuat dari CDN jsDelivr.
