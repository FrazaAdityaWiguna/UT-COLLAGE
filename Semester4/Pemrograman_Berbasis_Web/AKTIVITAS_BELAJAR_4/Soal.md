# Tugas Praktik 1 — Pemrograman Berbasis Web

Membuat aplikasi website menggunakan **HTML, CSS, dan JavaScript**, lalu menjelaskannya dalam sebuah **video**.

## Indikator Hasil Belajar

1. Mahasiswa dapat merancang struktur HTML yang **semantik** dan **valid**.
2. Mahasiswa dapat mengelola gaya antarmuka menggunakan CSS dengan tiga cara: **inline**, **internal**, dan **external**.
3. Mahasiswa dapat menggunakan JavaScript untuk:
   - manipulasi DOM,
   - validasi form,
   - manipulasi data tabel,
   - interaksi UI sesuai kreativitas masing-masing (misalnya pop-up, modal box, dan alert box).

## Kriteria Penilaian

| No  | Kriteria | Yang dinilai |
| --- | -------- | ------------ |
| 1.1 | Struktur HTML | Semantik, valid, dan lengkap |
| 1.2 | Desain CSS | Tampilan antarmuka dan penggunaan CSS |
| 1.3 | JavaScript DOM | Seberapa interaktif website dan bagaimana data dimanipulasi |
| 1.4 | Validasi Form & Alert | Memberi umpan balik (feedback) kepada pengguna saat terjadi kesalahan input |
| 1.5 | Modularitas & Struktur File | Pemisahan file dan kerapian struktur folder |
| 1.6 | Kreativitas Tambahan | Tema, fitur, dan UI |
| 1.7 | Video Penjelasan | Sistematika, alur berpikir, dan argumentasi dalam merancang serta membuat website dengan HTML, CSS, dan JavaScript |

## Yang Dikumpulkan

- Source code website (HTML, CSS, JavaScript).
- Video penjelasan yang membahas poin-poin kriteria di atas.
